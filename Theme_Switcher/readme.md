# 🎨 Theme Switcher

🚀 A simple web app that **switches between Light and Dark themes**.

🔗 **Live Demo**: [Theme Switcher](https://nikhilchikkam.github.io/Full-Stack/Theme_Switcher/)

---

## 🌟 Features
✅ **Type 'Light' or 'Dark' to switch themes**  
✅ **Or click the 'Switch Theme' button**  
✅ **Smooth UI transitions**  
✅ **Error Handling** (alerts user for invalid input)  
✅ **Responsive Design**  

---

## 🛠 Technologies Used
- **HTML** - Structure  
- **CSS (Bootstrap + Custom Styling)** - Styling  
- **JavaScript** - Theme switching
