# 📑 Bookmark Manager

🚀 A simple and elegant Bookmark Manager to save and organize your favorite websites. Built with **HTML, CSS, and JavaScript**, this project allows users to store site names with URLs and access them instantly.

🔗 **Live Demo**: [Bookmark Manager](https://nikhilchikkam.github.io/Full-Stack/Bookmark_Manager/)

---

## 🌟 Features
✅ **Add Bookmarks** - Save your favorite websites with a name and URL.  
✅ **One-Click Visit** - Click on the link to directly visit the site.  
✅ **Delete Bookmarks** - Remove saved bookmarks anytime.  
✅ **URL Validation** - Ensures only valid URLs are accepted.  
✅ **User-Friendly Design** - Styled with Bootstrap for a clean UI.  

---

## 🛠️ Technologies Used
- **HTML** - Page structure  
- **CSS (Bootstrap)** - Styling and responsiveness  
- **JavaScript** - Functionality (adding, deleting bookmarks, validation)
