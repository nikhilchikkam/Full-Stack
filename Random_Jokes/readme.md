# 😂 Random Jokes

🚀 A fun web app that **fetches random jokes** at the click of a button!

🔗 **Live Demo**: [Random Jokes](https://nikhilchikkam.github.io/Full-Stack/Random_Jokes/)

---

## 🌟 Features
✅ **Click a button** to get a new joke instantly  
✅ **Spinner (Loading Animation)** while fetching data  
✅ **Responsive UI** (works on all devices)  
✅ **Error Handling** (shows message if API fails)  

---

## 🛠 Technologies Used
- **HTML** - Structure  
- **CSS (Bootstrap + Custom Styling)** - Styling  
- **JavaScript (Fetch API)** - Fetching jokes
