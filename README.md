# 🚀 My Small Projects Repository

Welcome to my **Small Projects Repository**!  
This repository contains a collection of **independent mini-projects**, each designed to explore different technologies, concepts, and methodologies.  
Every project is housed in its own subdirectory and can be run independently.

---

## 📂 **Projects Overview**
Each project in this repository is built with different **tech stacks** and serves unique functionalities. Below is a categorized list of projects with live demo links.  

### 📝 **Productivity & Tools**
- ✅ [To-Do List](https://nikhilchikkam.github.io/Full-Stack/Todos/) – A task manager with **Local Storage** support.  
- 📖 [Bookmark Manager](https://nikhilchikkam.github.io/Full-Stack/Bookmark_Manager/) – Save and manage favorite websites efficiently.  
- 📚 [Library Management System](https://nikhilchikkam.github.io/Full-Stack/Library_Management/) – A simple library book-tracking app.  

### 🎮 **Fun & Games**
- ⏳ [Bomb Defuser Game](https://nikhilchikkam.github.io/Full-Stack/Bomb_Defuser/) – A countdown timer challenge!  
- ⌨️ [Speed Typing Test](https://nikhilchikkam.github.io/Full-Stack/Speed_Typing_Test/) – Measure your typing speed in real-time.  
- 🤖 [Chatbot](https://nikhilchikkam.github.io/Full-Stack/Chatbot/) – A simple **chatbot with pre-defined responses**.  
- 🎲 [Random Jokes](https://nikhilchikkam.github.io/Full-Stack/Random_Jokes/) – Get a random joke at a click!  

### 🔎 **Search & Information Apps**
- 🌍 [Countries Search](https://nikhilchikkam.github.io/Full-Stack/Countries_Search/) – Search for countries & view population stats.  
- 🔎 [Wikipedia Search](https://nikhilchikkam.github.io/Full-Stack/Wiki_Search_App/) – Fetch Wikipedia results dynamically.  
- 🔢 [Number Facts](https://nikhilchikkam.github.io/Full-Stack/Number_Fact/) – Learn fun facts about any number!  

### 🎨 **Customization & Converters**

- ⏱️ [Time Converter](https://nikhilchikkam.github.io/Full-Stack/Time_Converter/) – Convert **hours & minutes into seconds**.  
- ⌨️ [Key Code Identifier](https://github.com/nikhilchikkam/Full-Stack/tree/master/Key_Code) – Displays **key codes** of pressed keys.  
- 🕰️ [Peace Timer](https://github.com/nikhilchikkam/Full-Stack/tree/master/Peace_Timer) – A relaxing countdown timer.  

### 🏬 **E-Commerce & Shopping**

These projects utilize a variety of **front-end and back-end** technologies:
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
