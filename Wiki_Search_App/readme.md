# 🔎 Wikipedia Search

🚀 A simple web app that **fetches Wikipedia search results** based on user input.

🔗 **Live Demo**: [Wikipedia Search](https://nikhilchikkam.github.io/Full-Stack/Wiki_Search_App/)

---

## 🌟 Features
✅ **Type a search term** and press Enter to get results  
✅ **Displays relevant Wikipedia links & descriptions**  
✅ **Spinner (Loading Animation)** while fetching data  
✅ **Error Handling** for failed API requests  
✅ **Responsive UI** (works on mobile & desktop)  

---

## 🛠 Technologies Used
- **HTML** - Structure  
- **CSS (Bootstrap + Custom Styling)** - Styling  
- **JavaScript (Fetch API)** - Fetching Wikipedia results
