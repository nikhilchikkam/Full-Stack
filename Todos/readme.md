# 📝 To-Do List App

🚀 A simple and elegant **to-do list** that allows users to manage tasks efficiently.

🔗 **Live Demo**: [To-Do List](https://nikhilchikkam.github.io/Full-Stack/Todos/)

---

## 🌟 Features
✅ **Add and delete tasks easily**  
✅ **Mark tasks as completed**  
✅ **Tasks persist after refresh (Local Storage)**  
✅ **Bootstrap-based clean UI**  

---

## 📚 Concepts Learned & Applied
- **JavaScript Event Handling** (`click` events for adding/deleting tasks)  
- **DOM Manipulation** (dynamically creating task elements)  
- **Local Storage API** (saving and retrieving tasks)  
- **Bootstrap for styling** (modern & responsive UI)
