# 💣 Bomb Defuser Timer

🚀 A simple web app that **simulates a bomb countdown**, and users must type `'defuse'` before time runs out.

🔗 **Live Demo**: [Bomb Defuser Timer](https://nikhilchikkam.github.io/Full-Stack/Bomb_Defuser/)

---

## 🌟 Features
✅ **Countdown starts from 10 seconds**  
✅ **Type `'defuse'` and press Enter to stop the countdown**  
✅ **Displays BOOM if not defused in time**  
✅ **Provides feedback messages for better user experience**  
✅ **Mobile-friendly & responsive design**  

---

## 📚 Concepts Learned & Applied
This project helped in understanding and applying the following concepts:

1. **JavaScript Timers (`setInterval`)**
   - Implemented a countdown using `setInterval`
   - Stopped the timer using `clearInterval()`

2. **Event Handling**
   - Capturing user input with `keydown` event.
   - Checking user-entered text before defusing.

3. **DOM Manipulation**
   - Updating timer dynamically with `textContent`
   - Displaying result messages dynamically.

4. **Bootstrap for Styling**
   - Used Bootstrap classes for a clean and responsive layout.

5. **User Experience (UX) Enhancements**
   - Preventing defusal after countdown ends.
   - Providing feedback messages for correct and incorrect inputs.


## 🛠 Technologies Used
- **HTML** - Structure  
- **CSS (Bootstrap + Custom Styling)** - Styling  
- **JavaScript (setInterval, Event Handling)** - Timer countdown & input validation
