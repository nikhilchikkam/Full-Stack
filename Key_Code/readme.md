# ⌨️ Key Code Display

🚀 A simple web app that **displays the key codes** of any key you press.

🔗 **Live Demo**: [Key Code Display](https://nikhilchikkam.github.io/Full-Stack/Key_Code/)

---

## 🌟 Features
✅ **Type any key and see its Key Code**  
✅ **Auto-filters unnecessary keys (Shift, Ctrl, etc.)**  
✅ **Modern UI with Bootstrap Styling**  
✅ **Responsive Design**  

---

## 📚 Concepts Learned & Applied
This project helped in understanding and applying the following concepts:

1. **JavaScript Event Handling**
   - Capturing `keydown` events to detect key presses.
   - Using `event.key` and `event.code` to display accurate key information.

2. **DOM Manipulation**
   - Dynamically creating and appending elements (`li`) to the list.
   - Managing user input efficiently.

3. **Event Filtering**
   - Ignoring unnecessary keys like `Shift`, `Control`, `Alt`, etc.
   - Ensuring only valid keys are displayed.

4. **Bootstrap for Styling**
   - Utilizing Bootstrap for a clean and responsive UI.
   - Styling list items dynamically with Bootstrap classes.

5. **User Experience (UX) Improvements**
   - Auto-focusing on the input field for better usability.
   - Formatting key codes for better readability.

---

## 🛠 Technologies Used
- **HTML** - Structure  
- **CSS (Bootstrap + Custom Styling)** - Styling  
- **JavaScript** - Key code event handling
