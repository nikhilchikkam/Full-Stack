# ⏳ Time Converter

🚀 A simple web app that **converts hours and minutes into seconds**.

🔗 **Live Demo**: [Time Converter](https://nikhilchikkam.github.io/Full-Stack/Time_Converter/)

---

## 🌟 Features
✅ **Enter hours & minutes** and instantly get the result in seconds  
✅ **Validation for inputs** (prevents negative values, incorrect minutes)  
✅ **Error Handling** (displays helpful error messages)  
✅ **Responsive UI** (works on mobile & desktop)  

---

## 🛠 Technologies Used
- **HTML** - Structure  
- **CSS (Bootstrap + Custom Styling)** - Styling  
- **JavaScript** - Input validation and calculations
