# 💬 Chatbot

🚀 A simple chatbot that responds to user messages with pre-set replies.

🔗 **Live Demo**: [Chatbot](https://nikhilchikkam.github.io/Full-Stack/Chatbot/)

---

## 🌟 Features
✅ **Chatbot replies with pre-set responses**  
✅ **User messages appear on the right, bot responses on the left**  
✅ **Press Enter to send messages**  
✅ **Auto-scroll for a smooth chat experience**  
✅ **Modern UI with Bootstrap and responsive design**  

---

## 📚 Concepts Learned & Applied
This project helped in understanding and applying the following concepts:

1. **JavaScript Event Handling**
   - Capturing button clicks and `keydown` events (Enter key to send messages).

2. **DOM Manipulation**
   - Dynamically creating chat messages and appending them to the chat window.

3. **Auto-scrolling Chat Windows**
   - Ensuring the latest messages are always visible.

4. **Responsive Chat UI**
   - Using Bootstrap and CSS flexbox for a clean and user-friendly interface.

---

## 🛠 Technologies Used
- **HTML** - Page structure  
- **CSS (Bootstrap + Custom Styling)** - Styling  
- **JavaScript (DOM Manipulation)** - Chat functionality
