# 🕰️ A Moment of Peace

🚀 A simple web app that **allows users to take a timed break** with a countdown timer.

🔗 **Live Demo**: [A Moment of Peace](https://nikhilchikkam.github.io/Full-Stack/Peace_Timer/)

---

## 🌟 Features
✅ **Choose a timer duration (20s, 30s, 40s, 1min)**  
✅ **Live countdown updates**  
✅ **Automatically resets when time is up**  
✅ **Modern, minimalistic UI**  

---

## 📚 Concepts Learned & Applied
This project helped in understanding and applying the following concepts:

1. **JavaScript Timers (`setInterval`)**
   - Implemented a countdown using `setInterval`
   - Stopped the timer using `clearInterval()`

2. **Event Handling**
   - Handling button clicks to start different timers.
   - Managing multiple event listeners efficiently.

3. **DOM Manipulation**
   - Dynamically updating the timer text.
   - Clearing previous intervals to prevent overlapping.

4. **CSS & Bootstrap for Styling**
   - Used Bootstrap for a **clean and modern UI**.
   - Styled buttons for a **better user experience**.

5. **User Experience (UX) Enhancements**
   - Timer text updates in real-time.
   - Prevents multiple active countdowns.
