# 🔢 Number Facts

🚀 A simple web app that **fetches interesting facts about numbers**.

🔗 **Live Demo**: [Number Facts](https://nikhilchikkam.github.io/Full-Stack/Number_Facts/)

---

## 🌟 Features
✅ **Enter any number** to get a fun fact  
✅ **Automatic API Fetching** when pressing `Enter`  
✅ **Spinner (Loading Animation)** while fetching data  
✅ **Error Handling** for invalid inputs  
✅ **Responsive Design**  

---

## 🛠 Technologies Used
- **HTML** - Structure  
- **CSS (Bootstrap + Custom Styling)** - Styling  
- **JavaScript (Fetch API)** - Fetching facts
