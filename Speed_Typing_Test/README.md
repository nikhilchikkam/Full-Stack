# ⌨️ Speed Typing Test

🚀 A simple web app that **tests how fast you can type** a randomly generated quote.

🔗 **Live Demo**: [Speed Typing Test](https://nikhilchikkam.github.io/Full-Stack/Speed_Typing_Test/)

---

## **✨ Features**
✅ **Fetches a random quote** for you to type.  
✅ **Tracks the time** taken to type the quote.  
✅ **Instant feedback** on correctness.  
✅ **Displays results dynamically**.  
✅ **Modern UI with Bootstrap & CSS styling**.  

---

## **🛠 Technologies Used**
- **HTML5** – Page Structure  
- **CSS3 & Bootstrap** – Styling  
- **JavaScript (ES6+ Fetch API, setInterval)** – Timer & API calls  

---

## **🚀 How It Works**
1️⃣ **A random quote appears** for typing.  
2️⃣ **Timer starts automatically** when the quote loads.  
3️⃣ **Type the exact quote** in the input field.  
4️⃣ **Press "Submit"** – It checks if you typed it correctly.  
5️⃣ **See your typing speed** in seconds.
